一句话说明：这是一本只存在你自己设备上的日记本。我们不设账号、不开服务器、不收集你的任何个人信息，也看不到你写的任何一个字。

一、我们收集什么信息

不收集。本应用不要求注册、不要求登录、不收集姓名、手机号、邮箱、位置、设备标识、通讯录、相册、通讯内容，也不使用 Cookie 统计、埋点分析或第三方广告 / 推送 SDK。

你在应用里写下的日记、三件事、感恩、复盘、心情刻度、习惯打卡、年度目标、封面署名与寄语、宠物名称与状态，全部只保存在当前设备浏览器的本地存储（localStorage，键名 diary2027.v1）中，由浏览器自行管理，不会上传到任何服务器。

二、本地存储与离线使用

  • 应用通过 Service Worker 缓存页面资源，安装到桌面后断网也能打开、书写与查询。
  • 本地数据不会自动同步到云端，也不会在你的多台设备之间共享。同一网址在不同设备 / 不同浏览器里是各自独立的一本本子。
  • 清理浏览器数据、卸载应用、更换设备或浏览器，都会导致本地日记丢失且无法由开发者找回。应用内提供「导出 JSON 备份」「导入备份」，请定期自行备份。

三、唯一的外部网络请求

用途接收方发送内容可否关闭
获取当日天气Open-Meteo.com所选城市的经纬度可以
搜索城市经纬度Open-Meteo.com 地理编码接口你输入的地名可以

这两项请求不包含任何日记内容、不包含设备标识、不携带账号信息。在「设置 · 关于」中关闭「允许联网获取天气」后，应用不会发出任何外部网络请求，天气可改用「手记天气」，随当天日记一起保存在本机。

四、权限申请

本应用不申请定位、通讯录、相册、摄像头、麦克风、通知、蓝牙等系统权限。导入备份、导出文件、打印 / 存 PDF 均由你手动触发，文件只在本机读写，不上传。

五、信息共享、转让与公开披露

由于我们不持有你的数据，不存在共享、转让、公开披露或委托处理的情形。链接本身是公开的，但他人打开只会看到一本空白的新本子，无法读取你设备上的日记。

六、内容来源与知识产权

  • 古诗词多为公有领域作品；近现代名人语录、影视台词仅作节选与学习交流并尽量标注出处，不用于商业售卖或广告素材。
  • 「历史上的今天」为公开事实性事件的自撰简述；英文单词例句、每日一技与界面文案为原创整理。
  • 「今日小签」「运势」等为按日期生成的趣味内容，不构成任何预测、命理、医疗或决策依据。
  • 如第三方内容权利人认为相关内容不妥，可通过文末联系方式提出，我们会核实后删除或替换。

七、未成年人

本应用不收集任何个人信息，未成年人亦可使用，无需监护人另行授权。若设备为多人共用，监护人仍应留意设备本地数据的可见性。

八、你的权利

  • 查看 / 修改 / 删除：在应用内直接编辑或清空任意一天；「设置 · 关于」提供「清空全部日记」。
  • 导出：「导出 JSON 备份」「导出全年 Markdown」，文件保存在你的设备上。
  • 彻底删除：清空日记、清除浏览器站点数据或卸载应用即可；开发者侧没有任何副本。
  • 因我们不收集个人信息，不涉及个人信息查阅、更正、撤回同意等需向开发者提出的操作。

九、免责说明

法定节假日、调休安排与二十四节气依据公开资料整理，如有调整以官方最新发布为准。应用内容仅供参考，不替代医疗、法律、投资等专业意见。应用按「现状」提供，不对数据准确性、服务连续性作担保。

十、政策变更与联系方式

如政策有变更，会更新本页「最近更新」日期。应用本身零账号、零推送，不会主动向你发送通知。
